Extension dev harness

The side panel on the right is the real extension code from extension/, running in a normal page. Edit a file, then click ↻ Reload panel (or Ctrl+Shift+R) — no packing, no reinstall.

Real pages

Paste any job URL in the address bar. The server fetches it and shows it here with its scripts removed, so Fetch Job Details reads what the site sends. Boards that render with JavaScript only, or block server fetches (LinkedIn, Indeed), show less here than in a real browser. Check those in the real extension.

Good to know

  • ChatGPT: in the Bid tab press Connect ChatGPT. The job on screen and the next 4 get their CV written in the background, so opening a job shows its CV with a Download CV button. Add questions under Application questions (one per line) to get 2 to 3 sentence answers. ChatGPT tabs here are a stand-in that returns a SAMPLE CV and sample answers. With Dry run on, the CV is a sample PDF and nothing is saved. Real ChatGPT only works in the real extension.
  • Add & Next closes the job's tab and moves to the next tab (or an empty one). Open several postings in tabs, then work through them.
  • Dry run (on by default): Add & Next, Generate, Mark as Applied and other writes are answered by the harness and never saved. Sign-in, reads and the duplicate check use the real API.
  • Sign in with your normal account. Roles decide the tabs: bidder sees Bid, job_adder sees Add job, and admins see both.
  • Alt+Shift+F is the Autofill shortcut, as in Chrome.
  • Drag the bar between the page and the panel to try narrow and wide panels.
  • Requests shows every API call the panel makes.
  • Not covered here: the debugger-based typing into React dropdowns, the Save As dialog, and Chrome's permission prompts. Those still need the real extension.
